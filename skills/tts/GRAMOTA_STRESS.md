# Проверка ударений по локальному словарю «Грамоты»

Когда пользователь дал PDF орфоэпического словаря или просит нормативную сверку всей книги, сначала проверь, что PDF содержит текстовый слой (`pdfinfo`, `pdftotext`). Используй локальный файл: не добавляй словарь, текст книги и полный JSON-отчёт в публичный репозиторий.

## Запуск

Нужен Poppler (`pdftotext`). Передавай подготовленный **произносимый** текст: один UTF-8 `.txt` или каталог `.txt`-фрагментов. Сохрани исходник отдельно и зафиксируй локальные исправления опечаток.

```bash
python scripts/check_gramota_stress.py \
  --dictionary-pdf /absolute/path/orfoepicheskij_slovar.pdf \
  --input /absolute/path/spoken_chunks \
  --output /absolute/path/gramota_stress_audit.json
```

Если RUAccent или другой акцентуатор подготовил **аналитическую копию** тех же фрагментов с `+` или `U+0301`, сохрани её в отдельном каталоге с теми же именами файлов и добавь:

```bash
python scripts/check_gramota_stress.py \
  --dictionary-pdf /absolute/path/orfoepicheskij_slovar.pdf \
  --input /absolute/path/spoken_chunks \
  --marked-input /absolute/path/marked_chunks \
  --output /absolute/path/gramota_stress_audit.json
```

Скрипт извлекает страницы PDF, индексирует явно напечатанные ударные словоформы до поля транскрипции, проверяет каждое многосложное слово входа и записывает SHA-256 PDF и текстовых файлов. В отчёте есть счётчики по каждому файлу, словоформы с номером страницы и до 20 расположений для отсутствующих или неоднозначных форм. Сравнение с размеченной копией отдельно показывает расхождения ударений, замены `е/ё` и фрагменты, где слова не выровнялись.

## Как читать отчёт

| Статус | Значение | Следующий шаг |
|---|---|---|
| `exact` | Эта словоформа с одним ударением явно напечатана в PDF | Используй страницу как нормативную ссылку; проверь акустическое произношение отдельно |
| `ambiguous` | В PDF найдено несколько ударений для одинакового написания | Выбери значение по контексту, сверяясь с полной статьёй |
| `absent` | Точной словоформы нет в извлечённом словаре | Не считай это ошибкой и не переноси ударение с начальной формы без проверки |

Словарь ударений охватывает трудные слова выборочно, а формы в статьях часто приведены не полностью. Даже при исправном PDF значительная часть обычной прозы получит `absent`. Для таких слов используй другие нормативные словари «Грамоты», словарь Зализняка для изменения ударения при склонении, Викисловарь как дополнительную сверку. У данных Зализняка могут быть ограничения на коммерческое использование: проверяй лицензию конкретного источника. Silero Stress годится как независимая модель для поиска расхождений с RUAccent; совпадение моделей не заменяет нормативный словарь.

`marked_check.conflicts` — разногласия **разметки текста** со словарём, а не найденные ошибки готовой речи. Просмотри сначала часто повторяющиеся слова и места с омографами. `yo_or_spelling_differences` выделены отдельно: восстановление `ё` меняет буквенный текст и требует собственной проверки. `unaligned_files` часто возникают из-за `/`, апострофов и необычной пунктуации; не сопоставляй их слова по позиции автоматически. Сохраняй сырой вывод акцентуатора для разбора.

## Применение к TTS

Ударения из отчёта не следует автоматически вставлять в Qwen3-TTS. В одном пилоте Qwen CustomVoice `U+0301` исказил термин, а `+` был произнесён буквально; короткая инструкция о конкретных ударениях дала разборчивую речь и была подтверждена прослушиванием короткого и длинного фрагмента. Это наблюдение для одного голоса. При смене модели, голоса или текста повтори A/B на реальном фрагменте и проверь на слух.

Whisper проверяет сохранность слов, но не место ударения. Словарная сверка всей книги означает, что каждое слово получило статус поиска; она не означает, что все словоформы найдены или что каждый MP3 прослушан. В итоговом отчёте отдельно указывай покрытие PDF, нерешённые формы, расхождения акцентуаторов и фактический объём слуховой проверки.
