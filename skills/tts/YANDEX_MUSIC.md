# Подготовка и личная загрузка в Яндекс Музыку

Этот документ относится только к личной библиотеке пользователя. Для публичной карточки аудиокниги, автора и дистрибуции в Яндекс Книгах и Яндекс Музыке используй skill `music`.

## Что проверять заранее

Собственные треки загружаются через сайт или настольное приложение и предназначены для личного прослушивания. Перед загрузкой сверяй актуальную справку и ограничения интерфейса: лимиты и поддерживаемые профили могут меняться.

Не отправляй единственную локальную копию. Сохраняй мастер, а для сервиса создавай отдельные производные файлы.

Если единый мастер не подходит для загрузки или пользователю нужна навигация по главам, подготовь отдельный комплект пронумерованных частей и манифест с путями, названиями, длительностью, размером и хэшем. Части примерно по десять минут — удобная отправная точка, а не требование сервиса. Загружай их в собственный плейлист в нужном порядке; исходный мастер не изменяй.

Для новой версии книги используй отдельный личный плейлист, если пользователь выбрал этот вариант. Зафиксируй, какая версия файлов относится к каждому плейлисту; непроверенную запись обозначай в названии или описании и не смешивай её части с проверенным выпуском.

## Совместимый профиль

Если исходный mono/24 kHz MP3 получает нестабильные ошибки, рабочий совместимый вариант:

```bash
ffmpeg -hide_banner -loglevel error -y \
  -i chapter.mp3 \
  -map_metadata 0 \
  -ar 44100 -ac 2 \
  -c:a libmp3lame -b:a 96k \
  -id3v2_version 3 \
  chapter-yandex.mp3
```

Это наблюдавшийся практический обход, а не доказанная причина ошибок. В одном проекте единый mono/24 kHz мастер с пониженным битрейтом в итоге тоже был принят, хотя интерфейс сначала показал ошибку.

Перед загрузкой совместимых копий:

- полностью декодируй каждую;
- проверь `title`, `artist`, `album`;
- проверь размер каждого файла;
- сохрани исходную длительность;
- не заменяй локальный мастер производной версией.

## Поведение интерфейса

- `Uploading` означает только передачу файла.
- `Processing` может длиться несколько минут для длинной главы.
- Временная строка `Error uploading the track` не всегда окончательна: после завершения всех передач обнови страницу и проверь реальный список.
- Параллельная загрузка многих крупных файлов чаще даёт нестабильные ошибки. Повторяй неудачные главы по одной.
- Не оценивай успех по исчезновению временной строки.
- Успешный ответ промежуточного загрузчика, в том числе HTTP 200, не доказывает добавление трека в плейлист.

Успех подтверждён, только если после обновления страницы видны:

- правильные название и исполнитель;
- ожидаемая длительность;
- значок личного трека;
- активная кнопка воспроизведения.

Если единый мастер принят, это уже завершает основную выгрузку аудиокниги. Главы можно добавлять отдельно для навигации. Не удаляй дубликаты или принятые треки без явного согласия пользователя.

## Повторная ошибка загрузки

1. После неоднозначного результата обнови плейлист и проверь, не появился ли трек, прежде чем повторять отправку. Так не создаются дубликаты после запоздалой обработки.
2. Проверь один исходный файл полным декодированием, длительность и размер. Если ошибка повторяется с другим исправным файлом или в другом плейлисте, не перекодируй всю книгу вслепую.
3. Попробуй другой официальный клиент — сайт или настольное приложение. Если доступны, проверь также другую сеть и настройки VPN/прокси. Повторяй один файл с паузой; после нескольких одинаковых отказов останови очередь и сохрани состояние для возобновления.
4. Для диагностики сохрани время, файл, клиент, ссылку на плейлист и наблюдаемый результат сетевого запроса. Успешный `OPTIONS` при `POST` без HTTP-ответа не доказывает общий сбой сервиса и не указывает однозначно на файл, аккаунт или сеть.

При автоматизации у плейлиста должен быть один активный загрузчик. Храни манифест и подтверждённый облачный прогресс отдельно от локально подготовленных файлов; ограничь число повторов или интервал наблюдения, а после устойчивой ошибки передай конкретные данные диагностики владельцу. Официальные маршруты: [загрузка собственных треков](https://www.yandex.ru/support/music/ru/collection/uploading_own_tracks) и [обращение в поддержку](https://yandex.ru/support/music/ru/troubleshooting/feedback).
