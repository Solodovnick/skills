# PDF

Работай с исходным файлом как с эталоном: готовь результат по отдельному пути и заменяй оригинал только после проверки. Указывай абсолютные пути к входу и выходу; пути к скриптам считай относительно этой папки навыка.

## Маршрут

1. Сними инвентарь: `pdfinfo`, `pdftotext -layout`, `pdfimages -list` и `python scripts/inspect_pdf.py INPUT.pdf`. Зафиксируй число и размеры страниц, шифрование, формы, текст, изображения и страницы без извлекаемого текста.
2. Рендерь нужные страницы через `pdftoppm -f N -l N -png INPUT.pdf PREFIX` и смотри изображение. Для изменений оформления проверь все затронутые страницы, а не только успешный код возврата.
3. Выбери метод по устройству страницы: текстовый слой, отдельный объект изображения или надпись, уже слитая с растром. Подробности — в [очистке PDF](references/cleanup.md).
4. Для нового документа используй `reportlab`, для структуры и форм — `pypdf`, для поиска и точечного удаления текстовых наложений — `PyMuPDF`. Сохраняй поля формы и ссылки, когда они нужны; после записи открывай файл заново и проверяй их состояние.
5. Сверь исходник и результат через `python scripts/compare_pdf.py INPUT.pdf OUTPUT.pdf`, передав `--removed-text` и допустимые области `--allow-rect X0 Y0 X1 Y1` для намеренных правок. Без разрешённых областей скрипт требует полного визуального совпадения. Проверь читаемость, количество страниц, размеры, поворот, нужный текст и отсутствие удаляемого элемента. Расхождения вне области правки требуют объяснения или переделки.

## Скрипты

- `scripts/inspect_pdf.py`: короткий JSON-инвентарь страниц и вхождений заданной строки; требует `PyMuPDF`.
- `scripts/remove_text_overlay.py`: удаляет повторяющуюся текстовую надпись на всех страницах или в `--pages` с сохранением графики и изображений; требует `PyMuPDF`. Используй только когда текст извлекается точно и `search_for` находит ожидаемое число областей на каждой выбранной странице.
- `scripts/remove_overlay_stream.py`: удаляет один общий поток PDF, состоящий только из надписи, с выбранных страниц; требует `PyMuPDF`. Если такой поток есть, этот метод сохраняет нижележащий слайд точнее прямоугольного удаления.
- `scripts/replace_page_image.py`: заменяет уникальное изображение во весь лист на подготовленный PNG того же размера; требует `PyMuPDF`. Применяй после отдельной визуальной ретуши растровых страниц.
- `scripts/inpaint_raster.py`: локально восстанавливает 8-битное RGB-изображение по подготовленной чёрно-белой маске; требует `opencv-python-headless`. Для сложного фона сначала ищи чистый слайд с тем же оформлением как донор.
- `scripts/compare_pdf.py`: сверяет число страниц, геометрию, текст и области изменения при одинаковом рендере; требует `PyMuPDF`.

При отсутствии пакета запускай скрипты через `uv run --no-project --with pymupdf python scripts/NAME.py ...` или `uv run --no-project --with opencv-python-headless python scripts/inpaint_raster.py ...`. Poppler предоставляет `pdfinfo`, `pdftotext`, `pdfimages` и `pdftoppm`. Проверяй `--help` конкретного скрипта перед применением.

Ретушь слитого изображения восстанавливает закрытый фон приблизительно. Не называй такие пиксели исходными; оцени результат на полном разрешении страницы, особенно рядом с буквами, лицами и мелкими деталями.
