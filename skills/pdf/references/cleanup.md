# Очистка PDF

## Определи, где находится помеха

Проверь текст через `pdftotext -layout` и изображение страницы через `pdftoppm`. `pdfimages -list` покажет, содержит ли страница одно изображение во весь лист или несколько самостоятельных объектов. Команда `scripts/inspect_pdf.py --needle STRING` быстро покажет страницы с извлекаемой надписью. Сравни вывод с рендером: текст может присутствовать только внутри изображения.

### Извлекаемый текст

Если надпись видна через поиск, проверь список `page.get_contents()` на каждой странице. Если последний поток один и тот же для всех выбранных страниц и содержит только эту надпись, используй `scripts/remove_overlay_stream.py`: удаление потока сохраняет графику под ним точнее прямоугольной правки. Иначе используй `scripts/remove_text_overlay.py` с точной строкой и ожидаемым числом вхождений. `PyMuPDF` удаляет все символы, пересекающие найденный прямоугольник, поэтому скрипт сверяет полный извлечённый текст страницы до записи. При пересечении с другим текстом он останавливается. Графика и изображения сохраняются через `apply_redactions(images=0, graphics=0, text=0)` с прозрачной заливкой. Просмотри фон под надписью после удаления.

### Самостоятельное изображение или XObject

Выясни имя XObject, его положение и другие места использования. Удаляй только операцию рисования нужного объекта на нужной странице. Не удаляй общий ресурс по одному совпадению имени: один XObject может использоваться в другом месте документа. Сверь рендер до и после вне области объекта.

### Надпись слита с растром

Отдельного объекта для удаления уже нет. Разметь маску по исходному рендеру с запасом на полупрозрачные края. На однотонном фоне восстанови локальный цвет. Если тот же шаблон страницы есть без помехи, совмести и перенеси нужный участок из него: это сохраняет исходный рисунок лучше реконструкции. На градиенте или фотографии примени `scripts/inpaint_raster.py` и проверь несколько радиусов. Для повторяющегося знака на разных фонах можно получить форму маски из версии на белом фоне и применить её к цветному фону; обязательно проверь совпадение масштаба и положения. Оставь текст и содержательные элементы за пределами маски. Если скрытая часть важна и восстановить её нельзя, используй чистый исходный слайд или сообщи об ограничении. Заменяй только страницы, которым это необходимо, через `scripts/replace_page_image.py`, с разрешением не ниже исходного изображения; остальные страницы оставь структурными.

## Проверка

- Сравни число страниц, размер и поворот каждой страницы.
- Для текстовых страниц сравни извлечённый текст после удаления целевой строки.
- Рендерь исходник и результат с одинаковым разрешением. Передай намеренно изменённые области в `scripts/compare_pdf.py` через `--allow-rect` (координаты PDF в пунктах); по умолчанию любое визуальное отличие считается ошибкой. Изменившиеся пиксели вне размеченной области проверь отдельно.
- Просмотри каждую исправленную страницу целиком и увеличенную область правки. Проверь отсутствие фрагментов букв, ореолов и видимого прямоугольника ретуши.
- Для форм и ссылок отдельно проверь поля, аннотации, переходы и их значения; обычный рендер не подтверждает сохранность структуры.
- Проверяй шифрование и права исходника и результата: библиотеки могут записать файл без исходных настроек защиты.
